# 🚀 Швидкий старт (Quick Start)

## 📦 Що у вас є:

1. **witerok-news-plugin.php** - WordPress плагін для управління новинами
2. **posts.php** - API endpoint для React додатку
3. **README-WORDPRESS-SETUP.md** - повна інструкція

---

## ⚡ 3 кроки до запуску:

### 1️⃣ Завантажте файли на сервер

```
📁 public_html/
├── 📁 wp-content/
│   └── 📁 plugins/
│       └── 📁 witerok-news/
│           └── witerok-news.php  ← ЗАВАНТАЖТЕ ТУТ (перейменуйте з witerok-news-plugin.php)
│
└── 📁 api/
    └── posts.php  ← ЗАВАНТАЖТЕ ТУТ
```

### 2️⃣ Активуйте плагін

1. WordPress Admin → **Плагіни** → **Встановлені плагіни**
2. Знайдіть **"WiterOK News Manager"**
3. Натисніть **"Активувати"** ✅

### 3️⃣ Додайте новину

1. WordPress Admin → **📰 Новини WiterOK** → **Додати нову**
2. Заповніть:
   - Заголовок
   - Текст (в редакторі)
   - Зображення (праворуч: "Встановити зображення новини")
3. Натисніть **"Опублікувати"** 🚀

---

## ✅ Перевірка

1. **API:** Відкрийте https://witerok.com/api/posts.php (має показати JSON)
2. **React:** Запустіть `npm run dev` і відкрийте http://localhost:5173
