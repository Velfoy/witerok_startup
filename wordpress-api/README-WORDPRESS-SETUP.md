# 🔧 Інструкція по налаштуванню WordPress для новин WiterOK

## 📁 Що завантажити на сервер

### 1. Плагін для новин

**Файл:** `witerok-news-plugin.php`  
**Шлях на сервері:** `public_html/wp-content/plugins/witerok-news/witerok-news.php`

```
public_html/
└── wp-content/
    └── plugins/
        └── witerok-news/
            └── witerok-news.php  ← завантажте сюди
```

### 2. API endpoint

**Файл:** `posts.php`  
**Шлях на сервері:** `public_html/api/posts.php`

```
public_html/
└── api/
    └── posts.php  ← завантажте сюди
```

---

## 🚀 Покрокова інструкція

### Крок 1: Завантажте файли через FTP/FileZilla

1. Підключіться до FTP сервера witerok.com
2. Створіть папку: `public_html/wp-content/plugins/witerok-news/`
3. Завантажте `witerok-news-plugin.php` → перейменуйте на `witerok-news.php`
4. Створіть папку: `public_html/api/`
5. Завантажте `posts.php` в папку `api/`

### Крок 2: Активуйте плагін

1. Зайдіть в WordPress адмінку: `https://witerok.com/wp-admin`
2. Перейдіть: **Плагіни** → **Встановлені плагіни**
3. Знайдіть **"WiterOK News Manager"**
4. Натисніть **"Активувати"**

### Крок 3: Ви побачите нове меню

В лівому меню WordPress з'явиться новий розділ:

```
📰 Новини WiterOK
├── Всі новини
├── Додати нову
└── 🔌 API для React
```

### Крок 4: Додайте першу новину

1. Клікніть **"Новини WiterOK"** → **"Додати нову"**
2. Заповніть форму:
   - **Заголовок** - введіть назву новини
   - **Текст** - напишіть текст в редакторі (можна використовувати всі можливості WordPress)
   - **Зображення новини** (праворуч внизу) - натисніть "Встановити зображення новини"
3. Натисніть **"Опублікувати"** (справа зверху)

⚠️ **ВАЖЛИВО:** Тільки опубліковані новини будуть видні в React додатку!

### Крок 5: Перевірте API

Відкрийте в браузері:

```
https://witerok.com/api/posts.php
```

Ви маєте побачити JSON з новинами:

```json
[
  {
    "id": 1,
    "title": "Назва новини",
    "slug": "nazva-novyny",
    "excerpt": "Короткий опис...",
    "content": "Повний текст новини...",
    "date": "2026-01-15 12:00:00",
    "image": "https://witerok.com/wp-content/uploads/2026/01/image.jpg",
    "categories": [],
    "link": "https://witerok.com/news/nazva-novyny/"
  }
]
```

### Крок 6: Перевірте в React додатку

1. Запустіть локально: `npm run dev`
2. Відкрийте: `http://localhost:5173`
3. Прокрутіть до секції **"Новини"**
4. Ви маєте побачити ваші новини з WordPress!

### ✨ Стандартний WordPress інтерфейс

- Звична форма для додавання/редагування
- Вбудований медіа-завантажувач
- Візуальний редактор Gutenberg

- Автозбереження

## 🔌 API Endpoints

### Отримати новини

```
GET https://witerok.com/api/posts.php
```

#### Параметри:

- `limit` - кількість новин (за замовчуванням: 10)

#### Приклади:

```
GET https://witerok.com/api/posts.php?limit=6    # Отримати 6 новин
GET https://witerok.com/api/posts.php?limit=20   # Отримати 20 новин
```

## ❓ Поширені питання

### Новини не відображаються в React?

1. Перевірте що плагін **активований**
2. Перевірте що новина **опублікована** (не чернетка)
3. Відкрийте API в браузері: `https://witerok.com/api/posts.php`
4. Перевірте консоль браузера (F12) на помилки

### Зображення не відображається?

1. Перевірте що ви додали **Featured Image** (Зображення новини)
2. Зображення має бути **опубліковане** разом з новиною
3. Перевірте що файл зображення доступний (відкрийте URL зображення в браузері)

### Можна додавати категорії?

Так! Можна розширити плагін, додавши таксономії. Зараз API повертає порожній масив категорій.
