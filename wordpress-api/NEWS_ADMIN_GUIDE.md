# 📰 Управління новинами WiterOK - Інструкція

## 🎯 Що це?

Спеціальна админка для управління новинами з простими полями:

- ✏️ **Заголовок** - назва новини
- 📝 **Текст** - вміст новини
- 🖼️ **Зображення** - обкладинка (JPG, PNG, GIF)
- 🔄 **Статус** - чернетка або опублікована

## 📋 Шаги по установці

### ШАГ 1️⃣: Загрузьте файл на сервер

Скопіюйте файл `admin-news.php` з папки `wordpress-api/` на сервер:

```
public_html/admin/news.php
```

**Структура на сервері:**

```
public_html/
├── admin/
│   └── news.php          ← Админка новин
├── api/
│   └── posts.php         ← API (обновлён)
└── ...
```

### ШАГ 2️⃣: Відкрийте адмінку

Відкрийте в браузері:

```
https://witerok.com/admin/news.php
```

**Важливо:** Вам потрібно бути залогованим як адміністратор WordPress!

Якщо вас просять логін - введіть ваші дані адміністратора WordPress.

### ШАГ 3️⃣: Додайте першу новину

1. **Заголовок:** Введіть назву новини
2. **Текст:** Напишіть текст (можна копіювати з Word)
3. **Зображення:** Натисніть "Виберіть файл" та загрузьте фото
4. **Статус:** Виберіть "Опублікована" (щоб видна на сайті)
5. **Додайте новину:** Натисніть кнопку "➕ Додати новину"

**Готово!** Новина автоматично з'явиться на сайті. ✅

## 🎬 Фінальна робоча схема

```
1. ВИ добавляєте новину в адмінці
          ↓
2. Новина зберігається в БД (wp_witerok_news)
          ↓
3. React запитує API (/api/posts.php)
          ↓
4. API повертає JSON з новинами
          ↓
5. React показує новини на сайті
```

## 📱 Що можете робити

### Додавання новини:

```
1. Відкрийте https://witerok.com/admin/news.php
2. Заповніть поля (заголовок, текст, фото)
3. Натисніть "Додати новину"
4. Новина з'явиться на сайті
```

### Редагування новини:

```
1. Знайдіть новину в списку
2. Натисніть "Редагувати"
3. Змініть дані
4. Натисніть "Оновити новину"
```

### Видалення новини:

```
1. Знайдіть новину в списку
2. Натисніть "Видалити"
3. Підтвердіть видалення
```

### Чернетка:

```
Якщо вибрали статус "Чернетка" - новина
не буде видна на сайті, але збережена
в БД. Можна закінчити пізніше.
```

- **Заголовок:** "Тестова новина"
- **Текст:** "Це тестова новина для перевірки"

- Відкрийте https://witerok.com/api/posts.php
- Має бути JSON з вашою новиною

## 🐛 Проблеми

### ❌ "Access denied"

**Рішення:**

- Переконайтесь що залогована як адміністратор
- Если не адміністратор - попросіть админа доступу

### ❌ "Немає таблиці в БД"

**Рішення:**

- Таблиця створюється автоматично при першому відкритті
- Просто перезагрузьте сторінку

### ❌ Зображення не загружається

**Рішення:**

- Перевірьте розмір (максимум 5MB)
- Перевірьте формат (JPG, PNG, GIF)
- Перевірьте доступ до wp-content/uploads (755)

### ❌ Новина не видна на сайті

**Рішення:**

- Переконайтесь що статус "Опублікована" (не "Чернетка")
- Перезагрузьте сторінку
- Перевірте API: https://witerok.com/api/posts.php

## 📊 API Формат

Когда вы добавляете новину, API возвращает:

```json
[
  {
    "id": 1,
    "title": "Нова новина",
    "slug": "nova-novyna",
    "excerpt": "Перші 30 слів текста...",
    "content": "Весь текст новини як HTML",
    "date": "2025-03-15 10:30:00",
    "image": "https://witerok.com/wp-content/uploads/image.jpg",
    "categories": [],
    "link": "https://witerok.com/news/nova-novyna/"
  }
]
```

React автоматично обробляє цей JSON и показує новини на сайті! 📱
